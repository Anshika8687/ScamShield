🛡️ ScamShield — Android Application

Learn • Practise • Stay Safe

ScamShield is an Android application designed to help users build awareness of phishing, online scams, and suspicious links through interactive learning and practice.

✨ Features

Practice Modes: Practice recognising common scam scenarios, including fake bank agents, digital-arrest scams, fake job offers, and phishing links.

Quiz Challenges: Take scam-awareness challenges and earn XP as you practise.

Chat Simulator: Explore realistic conversation scenarios to learn how scammers may approach victims.

Link Detector: Check suspicious links using the app's link-checking feature.

Cyber Safety Lessons: Learn about common scams such as phishing, UPI fraud, KYC scams, fake jobs, lottery scams, and fake customer-care scams.

Progress Tracking: View your security score, XP, streak, level, statistics, and achievements.

Profile and Settings: Access your profile and app settings.

🛠️ Tech Stack
- Platform: Android (native)
- Language: Java
- IDE / Build: Android Studio, Gradle
- UI: XML layouts, custom shape drawables, custom View (Canvas)
- Libraries: AndroidX AppCompat, AndroidX Fragment (no third-party libraries)
- Storage: SharedPreferences (offline, no database, no account)
- Detection: rule-based link analysis (offline)
- Version control: Git and GitHub
- Testing: Android Emulator and physical device

🚀 Run the Project

Clone or download this repository.

Open the project in Android Studio.

Allow Gradle to sync and download the required dependencies.

Run the app on an Android emulator or a connected Android device.

🔐 Safety Disclaimer

ScamShield is intended for cybersecurity education and scam-awareness practice. Automated link checks can make mistakes; do not rely on this app alone to decide whether a link is safe. Never share passwords, OTPs, UPI PINs, or banking credentials with untrusted people.
